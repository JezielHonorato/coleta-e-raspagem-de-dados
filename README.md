# coleta-e-raspagem-de-dados

Projeto referente a disciplina IMD1152 - Coleta e Raspagem de Dados, do Bacharelado em Tecnologia da Informação.

Profa. Dra. Francimaria Nascimento (IMD / UFRN).

## Objetivos

- Explorar diversos métodos de coleta de dados
- Preparar os dados para uma possível etapa de análise de dados
- Avaliar os desafios nos processo de coleta e pré-processamento

## Estrutura

A equipe deve:

1. Escolher um problema;
2. Definir as fontes de dados e realizar a coleta dos dados:
3. A coleta deve observar os princípios éticos e utilizar mais de um método visto em sala de aula
4. Os dados coletados devem ser pré-processados e preparados para análise de dados
5. Preparar uma apresentação
